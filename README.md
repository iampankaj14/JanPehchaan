# JanPehchaan 🇮🇳
> **"Aapki Pehchaan, Aapka Adhikaar"**

JanPehchaan is a unified family-record and welfare-entitlement platform designed to bring citizen and family records together, prevent duplicate records, and make welfare scheme eligibility transparent and accessible.

---
# LIVE LINK: https://snappy-tundra-dhxozrs.tmp.now/
## 🌟 Key Features

- **Unified Family Record & Digital ID**: Digital identity management and family tree mapping.
- **Dynamic Welfare Scheme Matcher**: Automated eligibility matching for major government schemes (PM Kisan, Ayushman Bharat, PMAY, Old Age Pension, etc.).
- **Proactive Duplicate Review**: Intelligent similarity detection and human-in-the-loop verification to prevent unfair rejections.
- **Document Wallet**: Secure storage for citizen verification documents (Aadhaar, Ration Card, Income/Caste certificates).
- **Audit Timeline & Grievance Tracking**: Complete transparency on application status and grievance redressal.
- **Accessible & Multilingual Design**: High-contrast, dyslexia-friendly fonts, screen-reader support, and voice assistance.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 2. Backend Setup
```bash
cd server
npm install
cp .env.example .env   # Update with your Supabase credentials
npm run dev
```

### 3. Frontend Setup
```bash
cd client
npm install
npm run dev
```
