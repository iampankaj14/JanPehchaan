# JanPehchaan Assets Directory

Place your custom branding assets in this directory. The frontend will automatically display them!

### Supported Asset Files:
1. `logo.png` - Main JanPehchaan branding logo (Used in header & splash screen)
2. `emblem.png` - National / State emblem or secondary seal
3. `splash.png` - Splash screen hero graphic
4. `favicon.ico` or `favicon.png` - Browser tab icon

*Note: Clean SVG and PNG fallbacks are already pre-configured in the codebase so that the UI never breaks or displays broken image icons even if a file is missing.*
